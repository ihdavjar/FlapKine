Launching the Application
=========================

When you launch **Flapkine**, the **Main Window** appears.

.. image:: ../assets/images/main_window.png
   :alt: Main Window
   :align: center
   :width: 300px


You can either:

- **Create a New Project**

- **Open an Existing Project**


For details on the components in this interface, see the :doc:`Main Window <window/main_window>`.
