Windows Overview
================

This section describes all interface windows used in Flapkine. Each has a dedicated documentation page:

.. list-table::
   :widths: 25 75
   :header-rows: 1

   * - **Window**
     - **Description**
   * - :doc:`Main Window <window/main_window>`
     - Entry point for opening or creating projects
   * - :doc:`Project Editor Window <window/project_editor>`
     - View STL, select points, preview animations
   * - :doc:`Project Creator Window <window/project_creator>`
     - Setup scenes, adjust render settings
   * - :doc:`Scene Creator Window <window/scene_creator>`
     - Compose scenes using sprites
   * - :doc:`Sprite Creator Window <window/sprite_creator>`
     - Define object properties and orientation
   * - :doc:`InverseKinematics Window <window/inverse_kinematics>`
     - For solving Inverse Kinematics problems
