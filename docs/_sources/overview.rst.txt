📖 Overview
===========

**FlapKine** is a software toolkit for the kinematic analysis of flapping-wing mechanisms. Developed to support bio-inspired robotics and aerodynamics research, it provides an intuitive and customizable framework for analyzing forward and inverse kinematics.

Key features of FlapKine include:

- Support for arbitrary Euler angle sequences
- Modular transformation workflows
- Custom STL-based 3D animation and export

FlapKine was utilized in our studies to analyze a two-degree-of-freedom flapping-wing system. Its inverse kinematics computations were validated against stereo camera experimental data, processed via the Direct Linear Transformation (DLT) algorithm.

This streamlined system allows researchers to generate visualizations, perform parameter sweeps, and directly export STL animations for use in external solvers like CFD packages.

**Keywords**: Flapping-Wing Mechanisms, Bio-Inspired Robotics, Inverse Kinematics, Motion Tracking, DLT, Stereo Camera, STL, CFD
