Creating a New Project¶

To create a new project:

  1. Click New Project.

  2. Choose a project directory and name.

  3. You’ll enter the Project Creator Window. See 🔎 Project Creator Window for details.

Steps:

  1. Scene Setup: - 📁 Import existing scene OR - ✨ Create a new scene

    See 🎬 Creating a Scene

  2. Render Settings: - ✅ Load default settings (via checkbox) - ⚙️ Customize manually if needed

    See Render Configuration

  3. Hit Create Project to proceed to the Project Editor Window. See Project Editor Window for details.
