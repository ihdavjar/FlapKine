# FlapKine
The application provides a visual representation and simulation of the kinematics and aerodynamics of flapping wing micro-aerial vehicles. This tool lets users analyse and optimise MAV designs with precision and clarity by revealing flapping flight mechanics.

## Steps to Install the Application
1. Clone the github repository.
2. Open terminal and switch to the repository's directory.
3. Then install all the dependencies using `pip install .`
4. Then you can run the application using `python FlapKine.py`
